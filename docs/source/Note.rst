.. __Note:

.. NOTE::

   1. **Do not connect power to the Raspberry Pi USB-C port while using the PoE HAT—doing so may damage the board.  **  

   2. **The PoE HAT works with Raspberry Pi 3B+, 4B and 5, but the official Pi 5 active cooler is compatible only with Raspberry Pi 5. **  

   3. **Keep total continuous power below 25 W; if peripherals draw high power, use a switch that supports 802.3at and can provide at least 30 W with a 20 % margin.**
